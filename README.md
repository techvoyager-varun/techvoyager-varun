## Projects

### 🎬 [Filmory](https://github.com/techvoyager-varun/Filmory)

AI-powered movie discovery with personalized recommendations, watchlists, and explainable ranking. Combines neural collaborative filtering, sequential transformers, and adaptive re-ranking.

**Built with:** React · TypeScript · FastAPI · PyTorch · PostgreSQL  
[Explore the source →](https://github.com/techvoyager-varun/Filmory)

### 👨‍💻 [CodeCollab](https://github.com/techvoyager-varun/CodeCollab)

A collaborative coding workspace with a shared Monaco editor, voice and screen sharing, whiteboards, terminals, and project-aware AI assistance.

**Built with:** Next.js · Node.js · Socket.IO · WebRTC · PostgreSQL / pgvector · Redis  
[Try it live →](https://code-collab-ivory-five.vercel.app/) · [Explore the source →](https://github.com/techvoyager-varun/CodeCollab)
